# NEXPLAY

A lightweight, responsive browser-game portal with a blue/cyan theme.

## Run it
1. Extract the ZIP.
2. Open the `NEXPLAY` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. No build step, package installation, or account is required.

## Included
- Search and category filters
- Favourites saved in localStorage
- Recently played saved in localStorage
- Popular games section
- Responsive desktop / tablet / mobile layout
- Six built-in mini-games: Neon Snake, 2048, Tic-Tac-Toe, Reaction Rush, Memory Match, Cosmic Clicker, plus Pocket Pong
- External links to CrazyGames and itch.io for additional games

## Growing the catalogue
The current starter catalogue contains 8 entries, including built-in games and a discovery link. The site is designed so the catalogue can be expanded by adding entries to the `games` array in `index.html`. It is not preloaded with 500 verified third-party games. Only add games you have permission to link or embed, and check their terms and whether your school/network permits access.

## Important
NEXPLAY does not bypass school filters, network controls, ad blockers, or device security. It runs as a normal website and respects the browser and network it is used on.
